# Generators of O(L): complexity

## Algorithm and pinned source

The public consumer is `lattice.O().group_generators()`. For a marked lattice
the port's entry point is `automorphism_group_generators`
(`src/sage_indefinite_port/indefinite/marked_lattices.py:380-452`). For an
unmarked lattice it calls `RECURSION.orthogonal_group_generators`
(`src/sage_indefinite_port/indefinite/recursive.py:1134-1192`).

The pinned source is `INDEF_FORM_AutomorphismGroup` and its kernels in
`references/vendor/polyhedral_common@1592b246/src_indefinite/CombinedAlgorithms.h:887-1141`
and `:1289`, with the approximate model in
`src_indefinite/ApproximateModels.h:292` (Eichler criterion), `:407-526`
(`GetApproximateGroup`) and `:719-755` (`GetCoveringOrbitRepresentatives`).
The Lorentzian kernel is the perfect-domain traversal of
`src_lorentzian/lorentzian_perfect.h` and `LORENTZ_GetStabilizerGenerator`
(`src_lorentzian/fund_domain_vertices.h:508`).

## Notation for the invariants

| Symbol | Meaning |
| --- | --- |
| `n` | rank of `L` |
| `(p, q)` | signature; `m = min(p, q)` is the positive index of the signed view |
| `A = A_L` | discriminant group, `|A| = |det L|` |
| `ell` | length of `A`: `max_p dim_{F_p} A/pA` |
| `C(L)` | number of `O(L)`-orbits of perfect cells |
| `K` | number of covering orbits of the approximate model |

## Branches

`recursive.py:1150-1191` selects one branch from the reduced presentation
(`indefinite_reduced_presentation`, `indefinite_reduction.py:597`):

| Branch | Condition | Kernel |
| --- | --- | --- |
| Degenerate | radical `R != 0` | radical extension (`IndefiniteForms.g:1496-1511`) |
| Definite | `m = 0` | Plesken–Souvignier, through the Oscar bridge |
| Binary | `n = 2`, indefinite | reduction cycle of the binary form |
| Lorentzian | `m = 1`, `n >= 3` | perfect-domain traversal |
| Rank-four low Witt | `n = 4`, Witt index 0 or 1 | quaternion / Clifford models |
| Eichler | `m >= 2`, Witt index `>= 2` | approximate model plus covering orbits |

A case with `m >= 2`, Witt index `< 2` and no rank-four model raises
`UnfinishedCapability` (`recursive.py:1173-1182`). That case has no running
time.

## Degenerate branch

Write `L = L_0 ⊕ R` with `L_0` nondegenerate and `R` of rank `r`. Then
`O(L)` is generated by `O(L_0)`, `GL_r(Z)` on `R`, and the shears
`Hom(L_0, R)`. The generator count is `|gens O(L_0)| + 2 + r (n - r)`. The
cost is the cost of `O(L_0)` plus `O(n^2)` exact element operations per
generator. The test cases have `L_0 = <2>` (no search) or `L_0 = A2`
(definite branch).

## Definite kernel

The Plesken–Souvignier algorithm (Plesken and Souvignier, J. Symbolic
Comput. 24 (1997), §3) enumerates the short vectors of the basis norms and
runs a backtrack over them. For the definite lattices met here (rank `<= 18`,
root-lattice summands) the short-vector sets have at most a few thousand
elements, and the vector-sum invariants prune the backtrack to polynomial
size. Budget per call: `0.5 + 0.02 n^2` seconds, plus the bridge start cost
when the process has not used Oscar yet.

## Binary forms

For a binary form of discriminant `D`, `O(L)` is generated by `-1`, the
fundamental automorph, and an improper automorph when the form is ambiguous.
The fundamental automorph comes from one period of the reduction cycle. The
period length is `O(sqrt(D) log D)` (Buchmann and Vollmer, *Binary Quadratic
Forms*, Thm. 6.10.3; the regulator bound). Budget:
`0.3 + 0.002 sqrt(D) log2 D` seconds.

## Lorentzian route

`lorentzian_orthogonal_group_generators` (`lorentzian_cells.py:445`) traverses
the perfect complex. The cost is `C(L)` cells times the cost of one cell, plus
`C(L)^2` cell-equivalence tests. The per-cell cost and the theory of `C(L)` are
in `perfect-domains-and-lorentzian-cells.md` (owner C), sections "Cell cone",
"Facets and flips" and "Traversal".

When a case does not record `C(L)`, this file uses the bound
`C(L) <= 1 + ceil(sqrt d)`, with `d = min(|A|, |A_{L^v(e)}|)` and `e` the
exponent of `A`. The complex and `O(L)` do not change when `L` is replaced by
a rescaling or by `L^v(e)`. So a `p`-elementary lattice of length `ell` has
`d = p^min(ell, n - ell)`. The bound agrees with every count recorded in
`tests/fixtures/lorentzian_perfect_domains.json`. It is a model, not a
theorem. No published bound on `C(L)` in terms of `A_L` is known to this file.

Per cell, with `V ~ n(n+1)/2` configuration vectors and `~V/2` facet orbits,
each flip is one Fincke–Pohst search in rank `n - 1`
(`LORENTZ_FindPositiveVectors`, `lorentzian_perfect.h:397`):

`T_cell(n, A) = 0.5 + (V/2)(0.1 n + 0.01 sqrt|A|) + V^2 n U_ELT` seconds.

## Eichler route

If `L` contains `U ⊕ U`, the Eichler criterion holds: the `O(L)`-orbit of a
primitive vector `v` is determined by `q(v)` and `v/div(v) ∈ A_L`
(Gritsenko, Hulek and Sankaran, Compositio 143 (2007), Lemma 3.5). The
approximate group (`ApproximateModels.h:407-526`) is explicit: `SL_2(Z)` on the
hyperbolic part and Eichler transvections on a basis of the complement, `O(n)`
generators of size `O(n^2)`. The covering family has `K <= |A|` orbits for
the norm of the splitting vector. Each covering candidate costs one pointed
isometry, which recurses into `v^⊥`.

The splitting vector is positive in the signed view, so `v^⊥` has positive
index `m - 1`. When `m = 2`, `v^⊥` is Lorentzian after one step. A norm-2
vector of `U` gives `|A_{v^⊥}| = 2|A_L|`. The recursion is

`T(L) = 0.01 n^3 + K * 0.05 n^2 + T(v^⊥)`, with `K = min(|A|, 64)`.

The cap 64 is the number of covering orbits that a correct model visits for
the discriminant groups in this suite (`|A| <= 2^10`, at most `ell` cyclic
factors); larger `K` occurs only when `A_L` has many isotropic classes.

## Finite images

The acceptance cases compare generating sets by their images in `O(q_L)` and
in `O(L ⊗ F_p)` for the primes of `2 det L` and 3, 5, 7
(`tests/acceptance/consumer.py:assert_same_finite_images`).

- Image in `O(q_L)`: see `discriminant-groups-and-congruence-orbits.md`
  (owner F), sections "Discriminant group and its orthogonal group" and
  "Discriminant image of a set of isometries". Each discriminant morphism is
  `|A|` images of `n`-coordinate elements: `g |A| n U_ELT`.
- Reduction images: the order of a subgroup of `O(n, F_p)`. GAP's default
  method acts on the `(p^n - 1)/(p - 1)` projective points. For `n = 10`,
  `p = 7` that is `4.7 * 10^7` points: this method is pathological.
  Constructive recognition (Neunhöffer–Seress recognition, GAP package
  `recog`) is polynomial in `n` and `log p`. Budget per group:
  `1 + 0.002 n^3 log2 p * gens` seconds.

## Known worst cases

- Lorentzian lattices with large `d`: the cell count and the flip volumes
  both grow.
- Eichler route with many covering orbits: `K` approaches `|A|` when `A_L`
  has many classes of fixed norm.
- `m >= 2` and Witt index `< 2` outside rank four: no algorithm in the
  pinned source (`IndefiniteForms.g:830`).
